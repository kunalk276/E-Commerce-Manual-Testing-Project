# E-Commerce Website Manual Testing Project

## Project Overview

This repository contains manual testing artifacts for an E-Commerce web application. The objective of this project is to validate core functionalities of the application and identify defects using standard QA practices.


## Modules Tested

The following modules were covered during testing:

- User Login and Registration
- Product Search
- Add to Cart
- Checkout and Order Placement


## Testing Type Performed

- Functional Testing
- Smoke Testing
- Regression Testing
- UI Testing
